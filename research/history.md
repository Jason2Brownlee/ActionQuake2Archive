# Action Quake 2 Release History

Reconstructed history of Action Quake II.

## v0.82

Released as `actn82cl.zip` on April 03 1998.

Mentioned on the Action Quake 2 homepage:

> Friday - April 3, 1998 - Cail (9:03pm CST)
>
> The file is there! (v.82)   ftp://ftp.telefragged.com/pub/action/actn82cl.zip   Go and get it now....
Some people have been having problems with setting it up. Check your action.doc in the zip, it tells you all the commands, etc.
>
> To install, simply unzip the file into your \quake2\action directory... There's an icon there actq2.ico, if you want to use it...
>
> Good server up at 157.252.163.44! Go there now!
>
> We still need more people to set up servers though, drop me an email with the ip for a mention...

-- [http://action.telefragged.com/oldnews.htm](https://web.archive.org/web/20030804020826/http://action.telefragged.com/oldnews.htm)

There was no mention of this release in the historical changelog of later releases.

## v0.82 Fix

A fix for v0.82 version was released later the same day as `gamex86.dll`.

Mentioned on the Action Quake 2 homepage:

> Friday - April 3, 1998 - Cail (11:20pm CST)
>
> There was a problem where unique weapons would permanently disapear if someone disconnected while holding one.. that is now fixed.. get the new gamex86.dll here if you run a server and downloaded the zip before hearing about this bug (11CST, April 3rd)

-- [http://action.telefragged.com/oldnews.htm](https://web.archive.org/web/20030804020826/http://action.telefragged.com/oldnews.htm)

There was no mention of this release in the historical changelog of later releases.

## v0.85

Released as `???` (perhaps `ver85dll.zip` and/or `actn85cl.zip`) on April 05 1998.

Mentioned on the Action Quake 2 homepage:

> Sunday - April 5, 1998 - Cail (12:20am CST)\
>
> Version .85 release is out! This is just a gamex86.dll update, you don't need to download the 3.5 meg file... but it's now in the client pak if you are reading this and haven't downloaded the pak yet, don't worry about it, it's been updated. Also, we are pretty sure it is server side only, but just in case it might be a good idea to grab it if yer a client...

-- [http://action.telefragged.com/oldnews.htm](https://web.archive.org/web/20030804020826/http://action.telefragged.com/oldnews.htm)

Changelog from later readmes:

> New in v.85
>
> * Short falls do not cause fall damage (although long falls still cause the same amount of damage)
> * The handcannon now shoots 35 pellets each 3 times as powerful as each of the 100(!) pellets it used to shoot.  The result: the handcannon still works the same, except it might be more random at long distances (which is good) We did this to fix the multiple overflow errors the handcannon had caused.
> * Items (kevlar vest, silencer, lasersight) now spawn even if you decide to play more than one game!
> * Lava now deals damage normally.
> * The clips and magazines are now fullbright, and much easier to see.
> * Bandaging is now independent of reloading (ie you shouldnt be healed when you reload the shotgun)

## v0.86

Released as `ver86dll.zip` on April 05 1998.

Mentioned on the Action Quake 2 homepage:

> Sunday - April 5, 1998 - Cail (10:30pm CST)
>
> If you run a server, PLEASE use DMFLAGS of 16! Otherwise, unwanted bugs appear. Eventually we will redo the dmflags for our mod, but for now, just keep them at 16 (the default)...\
PLEASE STOP USING OFFICE.BSP. It's slow and clumsy, and now it's broken. Expect office2.bsp tomorrow!
>
> New server side only patch out v.86, but don't get it unless you run a server... It should allow playing on any level, but will make office.bsp look like crap (well, more like crap =P ).. q2 doesn't like targeted stuff (lights for example) on DM.. prolly b/c of lag, and we originally re-added it to make cool emergency lights in my level. Therefore, now that we are re-removing it permently, my map will look horrible, and have bugs and stuff. SO, i will be releasing a office2.bsp tomorrow that will:
>
> * Only have normal lighting, no emergency lighting...
> * Will have a much smaller outside area, and higher walls so as to (hopefully) speed up the map a LOT..
> * Will have various details removed or toned down to improve framerates.. the map is lagging people bad.. i might have to take out that bulldozer =(

-- [http://action.telefragged.com/oldnews.htm](https://web.archive.org/web/20030804020826/http://action.telefragged.com/oldnews.htm)

There was no mention of this release in the historical changelog of later releases.

## v0.87

Released as `ver87dll.zip` on April 06 1998.

Mentioned on the Action Quake 2 homepage:

> Monday - April 6, 1998 - Cail (11:10pm CST)
>
> Pietro. Kills bugs. Dead.\
> Heh, it seems as if we have FINALLY crushed that one server-crashing monkey-wrench bug that was causing page faults for our generous server donating friends. We linked it to being able to break windows. The moral of the story: if Id says 'don't put this in deathmatch' in the .dll code, they prolly know what they're talking about. Doh...
>
> Servers should be completely stable now, so if you run a server, or just feel like being all up-to-date, snag this ver87dll.zip.

-- [http://action.telefragged.com/oldnews.htm](https://web.archive.org/web/20030804020826/http://action.telefragged.com/oldnews.htm)

Changelog from later readmes:

> New in v.87
>
> * Servers no longer crash because of windows (we removed windows - if id tells you that you shouldn't have something in deathmatch, they mean it!)
> * Gibbing should no longer occur, even with telefragging and the handcannon.
